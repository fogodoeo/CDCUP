# 크레와트 시네마틱 선택 장면 제작 지침 v1

## 1. 목적

크레와트의 질문 화면을 단순한 질답지가 아니라, 사용자의 선택이 장면에 영향을 미치는 짧은 체험으로 만든다.

실제 동영상 파일을 사용하지 않고 정지 삽화, 전경 인물, 카메라 이동, 장면 교체를 조합해 영상과 비슷한 흐름을 구현한다.

핵심 경험은 다음 한 줄로 정의한다.

> 두 가능성을 바라보는 나 → 한쪽으로 향하는 카메라 → 선택한 상황 안에 들어간 나

## 2. 기본 제작 구조

질문마다 배경 삽화 3장을 제작한다.

1. `neutral`: 선택 전 양갈래 장면
2. `left`: 왼쪽 선택 이후의 중앙 장면
3. `right`: 오른쪽 선택 이후의 중앙 장면

사용자를 나타내는 백지 인물은 배경에 직접 그리지 않는다. 공통으로 재사용하는 투명 전경 자산으로 분리한다.

- `avatar-neutral`: 양쪽을 바라보는 뒷모습 반신
- `avatar-left`: 머리와 어깨가 왼쪽으로 약간 향한 반신
- `avatar-right`: 머리와 어깨가 오른쪽으로 약간 향한 반신

배경 36장과 공통 인물 3장을 기본 자산 단위로 삼는다.

## 3. 선택 전 장면

- 좌우 상황은 중앙을 향해 약 35~45도 기울어진 구도로 만든다.
- 중앙에는 사용자가 선택할 수 있는 시각적 통로를 남긴다.
- 두 상황의 크기와 밝기를 비슷하게 유지해 어느 한쪽이 정답처럼 보이지 않게 한다.
- 화면 하단 중앙 30%는 반신 인물이 올라갈 자리이므로 핵심 대상이나 작은 정보를 배치하지 않는다.
- 사용자를 나타내는 인물은 배경 이미지에 포함하지 않는다.
- 친구 등 문항에 필요한 보조 인물만 배경에 넣을 수 있다.

## 4. 선택 이후 장면

- 선택한 상황이 화면 중앙을 차지하는 정면 또는 정면에 가까운 구도로 만든다.
- 선택하지 않은 상황이나 그 행동을 결과 이미지 안에 넣지 않는다.
- 핵심 대상은 가로 18~82%, 세로 8~90%의 안전 영역 안에 둔다.
- 모바일에서도 잘리지 않도록 중요한 크레, 사육장, 보조 인물을 가장자리 가까이에 배치하지 않는다.
- 선택 전 장면과 방의 재질, 조명, 사육장 형태, 시선 높이를 최대한 동일하게 유지한다.
- 결과 장면은 단순 확대가 아니라 선택의 결과가 실제로 드러나야 한다.

예시:

- 대화를 선택하면 맞은편에 친구가 나타난다.
- 혼자 정리하기를 선택하면 조용한 전시 공간만 남는다.
- 미리 준비하기를 선택하면 완성된 사육장이 중앙에 나타난다.
- 다시 비교하기를 선택하면 두 개체가 같은 크기로 나란히 나타난다.

## 5. 반신 백지 인물

### 형태

- 머리, 목, 어깨, 상반신만 보이는 뒷모습으로 제작한다.
- 허리 아래는 원래부터 화면 하단 밖에 있는 구도여야 한다.
- 인물의 하단은 닫힌 둥근 형태가 아니라 캔버스 아래로 자연스럽게 이어져야 한다.
- 얼굴, 귀, 머리카락, 옷, 성별, 나이, 관절, 손가락을 표현하지 않는다.
- 따뜻한 아이보리색 종이 질감과 얇은 목탄색 외곽선을 유지한다.

### 배치

- 전경 레이어로 화면 하단 중앙에 고정한다.
- 배경의 바닥, 책상, 의자와 물리적으로 접촉시키지 않는다.
- 인물은 항상 배경보다 앞에 있는 관찰자 시점으로 보이게 한다.
- 선택 전과 결과 장면에서 크기와 높이를 동일하게 유지한다.
- 방향 변화는 머리와 어깨의 작은 회전만 사용한다.

### 금지

- 전신 인물
- 발이 바닥에 닿는 장면
- 책상 사이 또는 수납공간 안에 서 있는 장면
- 앉기, 쪼그리기, 무릎 꿇기
- 작은 물건을 잡거나 가리키는 동작
- 크레나 나뭇가지를 직접 만지는 동작

## 6. 애니메이션 타임라인

한 번의 선택 연출은 약 800~900ms로 구성한다.

| 시간 | 연출 |
|---|---|
| 0ms | 선택 입력 |
| 0~180ms | 선택 전 장면이 선택 방향으로 이동하며 약 1.1배 확대 |
| 180~420ms | 선택 전 배경에서 결과 배경으로 교차 전환 |
| 180~420ms | 반신 인물도 선택 방향 자산으로 교체 |
| 420~650ms | 결과 장면이 1.03배에서 1배로 안정됨 |
| 650~900ms | 다음 질문으로 전환 |

전환 순간에만 최대 1~2px의 짧은 초점 변화나 종이 질감 플래시를 허용한다.

선택하지 않은 장면을 검게 덮거나 계속 흐린 상태로 남겨두지 않는다. 카메라 이동 과정에서 화면 밖으로 밀어낸 뒤 결과 이미지에는 포함하지 않는다.

## 7. 포인터와 터치 동작

### 데스크톱

- 선택지에 마우스를 올리면 카메라가 해당 방향으로 조금 이동한다.
- 선택한 버튼은 앞으로 떠오르고, 반대 버튼은 크기와 대비가 낮아진다.
- 마우스가 빠지면 선택 전 상태로 자연스럽게 돌아간다.
- 클릭하면 전체 선택 연출을 재생한 뒤 다음 질문으로 이동한다.

### 모바일

- 호버 상태를 전제로 하지 않는다.
- 터치하면 선택 연출을 즉시 시작한다.
- 결과 장면을 최소 400ms 이상 보여준 뒤 다음 질문으로 이동한다.
- 너무 빠른 선택 방지 시간 안에는 장면을 바꾸지 않고 경고만 표시한다.

### 키보드

- 포커스가 들어온 선택지는 데스크톱 호버와 같은 미리보기를 제공한다.
- Enter 또는 Space 입력은 클릭과 같은 확정 연출을 실행한다.

## 8. 반응형 규칙

- 삽화의 내부 좌표계는 모든 환경에서 `3:2`로 고정한다.
- 삽화 전체를 보여주는 것을 우선하며 `object-fit: contain`을 사용한다.
- 장면 컨테이너는 반드시 `overflow: hidden`을 적용한다.
- 카메라 이동량은 픽셀이 아니라 컨테이너 폭의 비율로 계산한다.
- 데스크톱, 태블릿, 모바일에서 같은 핵심 대상이 보여야 한다.
- 320px, 375px, 390px, 768px, 1280px 이상에서 가로 넘침을 검사한다.
- 모바일에서는 반신 인물 너비를 장면 폭의 약 27~32%로 제한한다.
- 선택지 카드가 인물의 머리나 크레의 얼굴을 가리지 않게 한다.

## 9. 크레스티드게코 종 고증

모든 크레는 `Correlophus ciliatus`로 즉시 알아볼 수 있어야 한다.

- 넓은 삼각형 머리
- 매우 큰 눈과 눈꺼풀이 없는 형태
- 눈 위에서 시작해 등 양쪽으로 이어지는 속눈썹 같은 볏
- 미세하고 과도하지 않은 피부 질감
- 네 개의 다리
- 접착 패드가 보이는 발가락
- 적당히 굵은 잡는꼬리
- 나뭇가지를 붙잡는 자연스러운 수목성 자세

다음 형태가 보이면 폐기한다.

- 레오파드게코
- 가고일게코
- 이구아나
- 카멜레온
- 비어디드래곤
- 스킨크 또는 일반 도마뱀 형태
- 추가 다리, 중복 꼬리, 비정상적인 발가락

## 10. 소품과 신체 오류 방지

다음 소품은 원칙적으로 사용하지 않는다.

- 휴대폰, 태블릿, 노트북, 모니터
- 사진, 엽서, 종이 기록지, 체크리스트
- 화면 속 화면
- 글자, 숫자, 로고가 필요한 물건
- 앞뒤와 위아래가 중요한 얇은 휴대 물체
- 손가락으로 조작해야 하는 작은 장치

필요한 정보는 인물의 손동작이 아니라 공간의 상태와 대상의 배치로 표현한다.

허용하는 요소:

- 사육장
- 선반
- 안정적인 책상이나 카운터
- 고정된 조명
- 큰 의자나 벤치
- 고정된 가지와 코르크 구조물
- 글자가 없는 단순한 벽면 표식

## 11. 보조 인물 규칙

- 친구나 행사 참가자가 필요한 문항에만 사용한다.
- 주인공과 구별되도록 옅은 회색 종이 질감으로 표현한다.
- 책상이나 카운터 뒤에 안정적으로 앉아 상반신만 보이게 할 수 있다.
- 손은 보이지 않게 하거나 편 상태로 단순화한다.
- 보조 인물이 화면 하단 중앙의 주인공 자리를 침범하지 않게 한다.
- 기괴한 신체, 공중에 뜬 자세, 가구와 겹친 몸이 있으면 폐기한다.

## 12. 성능과 로딩

- 최종 배경은 WebP 또는 AVIF로 저장한다.
- 1536×1024 원본을 기준으로 장당 약 250~500KB를 목표로 한다.
- 현재 질문의 3장과 다음 질문의 선택 전 이미지만 미리 불러온다.
- 보이지 않는 나머지 질문 이미지는 지연 로딩한다.
- 장면 전환 전 `img.decode()` 완료 여부를 확인해 빈 화면을 방지한다.
- 캐시 키는 삽화 세트 버전과 함께 변경한다.

## 13. 접근성

- `prefers-reduced-motion: reduce`에서는 카메라 이동과 확대를 제거한다.
- 모션 감소 환경에서는 150ms 이내의 단순 교차 전환만 사용한다.
- 삽화는 질문 이해를 돕는 보조 수단이며, 선택지 문장만으로도 의미가 전달되어야 한다.
- 장식용 결과 이미지와 전경 인물은 스크린리더에서 제외한다.
- 질문 삽화의 대체 텍스트는 상황을 한 문장으로 설명한다.

## 14. 파일명과 데이터 규칙

권장 파일명:

```text
question-c01-neutral-v2.webp
question-c01-left-v2.webp
question-c01-right-v2.webp
avatar-half-neutral-v1.webp
avatar-half-left-v1.webp
avatar-half-right-v1.webp
```

질문 데이터는 다음 구조를 사용한다.

```js
{
  C01: {
    neutral: 'question-c01-neutral-v2.webp',
    left: 'question-c01-left-v2.webp',
    right: 'question-c01-right-v2.webp',
    avatar: true
  }
}
```

선택지가 무작위로 좌우 반전되면 다음을 함께 처리한다.

- 왼쪽과 오른쪽 결과 이미지 경로 교체
- 배경 좌우 반전
- 왼쪽과 오른쪽 반신 인물 경로 교체
- 카메라 이동 방향 교체

## 15. 이미지 생성 프롬프트 공통 조건

모든 질문 프롬프트에 다음 조건을 포함한다.

```text
현대의 현실적인 크레스티드게코 사육 또는 행사 공간.
세련된 흑백 모의고사 삽화풍, 섬세한 연필·잉크 선과 옅은 회색 명암.
가로 3:2, 하나의 자연스러운 시점과 수평선.
화면 하단 중앙 30%는 공통 반신 인물 레이어를 위해 비워둘 것.
주인공을 배경에 그리지 말 것.
휴대폰, 화면, 사진, 엽서, 종이, 글자, 로고, 작은 물건을 잡는 손을 넣지 말 것.
크레스티드게코는 실제 Correlophus ciliatus의 머리, 볏, 눈, 발가락 패드, 꼬리를 정확히 표현할 것.
마법학교, 로브, 판타지 요소를 넣지 말 것.
```

## 16. 문항별 제작 절차

1. 문항과 두 선택지의 차이를 한 문장으로 정리한다.
2. 손이나 화면 없이 공간 상태로 차이를 표현할 수 있는지 확인한다.
3. 선택 전 양갈래 구도를 먼저 제작한다.
4. 선택 전 이미지의 재질과 조명을 기준으로 왼쪽 결과 이미지를 제작한다.
5. 같은 기준으로 오른쪽 결과 이미지를 제작한다.
6. 크레 종 형태와 보조 인물 신체를 확대 검수한다.
7. 반신 전경 인물을 합성한 웹 화면에서 가림 여부를 확인한다.
8. 데스크톱과 모바일에서 양쪽 선택을 각각 실행한다.
9. 반대 장면이 결과 이미지에 남지 않는지 확인한다.
10. 통과한 이미지에만 최종 버전명을 부여한다.

## 17. 최종 검수표

### 장면

- [ ] 선택 전에는 두 가능성이 같은 비중으로 보인다.
- [ ] 선택 후에는 고른 상황만 중앙을 채운다.
- [ ] 선택하지 않은 행동이나 인물이 결과 장면에 남지 않는다.
- [ ] 세 이미지가 같은 공간과 조명처럼 느껴진다.
- [ ] 화면 하단 중앙의 핵심 정보가 반신 인물에 가려지지 않는다.

### 인물

- [ ] 주인공은 배경과 분리된 반신 레이어다.
- [ ] 허리 아래가 보이지 않는다.
- [ ] 가구, 바닥, 사육장과 물리적으로 겹치지 않는다.
- [ ] 성별과 나이를 특정할 요소가 없다.
- [ ] 손이나 작은 물건을 잡는 장면이 없다.

### 크레

- [ ] 실제 크레스티드게코로 보인다.
- [ ] 볏, 눈, 발가락, 꼬리가 자연스럽다.
- [ ] 추가 다리나 중복 꼬리가 없다.
- [ ] 나뭇가지와 몸의 접점이 자연스럽다.

### 반응형과 기능

- [ ] 320px에서도 가로 스크롤이 생기지 않는다.
- [ ] 선택지와 삽화가 겹쳐 읽기 어렵지 않다.
- [ ] 좌우 무작위 반전 후에도 문장과 장면이 일치한다.
- [ ] 마우스, 터치, 키보드에서 동일한 선택 결과가 나온다.
- [ ] 모션 감소 설정에서 기능이 유지된다.
- [ ] 다음 이미지가 늦게 나타나는 빈 화면이 없다.

## 18. 완료 기준

다음 조건을 모두 만족해야 한 문항이 완료된 것으로 본다.

- 선택 전, 왼쪽, 오른쪽 이미지가 모두 검수됨
- 반신 인물과 합성했을 때 깊이 오류가 없음
- 크레스티드게코 종 고증 통과
- 문장과 장면의 의미가 일치함
- 데스크톱과 모바일 양쪽 선택 검증 완료
- 반대 장면 노출과 가로 넘침 없음
- 압축과 캐시 키 반영 완료
